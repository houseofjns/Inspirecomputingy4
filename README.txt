HOUSE OF J&S COMPUTER TRAINING CENTER
INSPIRE COMPUTING INTERNATIONAL · YEAR 4
BILINGUAL LEARNING PORTAL · OFFLINE-READY PACKAGE

1. RUN THE WEBSITE
- Extract the ZIP into a folder.
- For a quick local preview, open index.html in a modern browser.
- For offline caching / service-worker support, serve the folder over localhost or HTTPS.
  Example: use a local static web server, or publish the folder to GitHub Pages.
- All HTML, CSS, JavaScript, logo and original SVG diagrams needed by the portal are included.

2. STUDENT LOGIN
- Enter the student's name.
- Access password: HJS2026
- The login is a client-side convenience gate; it is not server authentication.
- Use Log out to lock the portal again.

3. COURSE CONTENT
The portal follows the Year 4 Inspire Computing structure:
Unit 1 — Online Safety
Unit 2 — Searching and Comparing
Unit 3 — Desktop Publishing
Unit 4 — Programming (Part 1)
Unit 5 — Graphics Manipulation and Copyright
Unit 6 — Programming (Part 2)

Each unit contains 15 learning sections: overview, objectives, detailed bilingual notes,
topic explanations, definitions, examples, tables/diagrams, step-by-step guidance,
practical activities, workbook answer support, exam points, glossary, slide outline,
knowledge-check quiz and a 60-minute unit examination.

4. WORKBOOK ANSWER GUIDE
- The uploaded Inspire Computing Year 4 Workbook Answer Sheet is used as the answer source.
- Where it labels an activity “Student's own answer”, the portal preserves that as an open-ended task.
- Where no separate answer entry appears in the uploaded key, the portal says so and recommends teacher review.
- Do not treat generated practice examples as Pearson's official answer key.
- Original Student Book / Workbook / Answer Sheet PDFs and scanned page images are intentionally NOT included in this ZIP.

5. QUIZZES AND EXAMINATIONS
- Each unit has a 10-question knowledge-check quiz with feedback and retry.
- Each independent unit paper contains 84 questions / 100 marks / 60 minutes:
  Section A: 30 multiple-choice (30 marks)
  Section B: 20 fill-in-the-blank (20 marks)
  Section C: 20 matching (20 marks)
  Section D: 10 short questions (10 marks)
  Section E: 4 extended responses (20 marks)
- Exam password: HJS2026
- Essay/extended-response automated scores are provisional and require teacher review.
- Browser fullscreen and before-unload warnings are deterrents only. A client-side website cannot guarantee
  tamper-proof lockdown, prevent developer-tools access, or force fullscreen on every device.
  For high-stakes examinations use a managed exam platform with server-side controls.

6. STUDENT PROGRESS AND PRIVACY
- Progress and practice history are stored in the browser's local storage for that browser profile.
- Clearing browser data may remove saved progress.
- Do not use shared/public devices for private student information unless supervised.
- No external paid libraries or online fonts are required.
